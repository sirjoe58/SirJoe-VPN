# SirJoe VPN
Pannello di controllo per Cloudflare WARP (Windows).

1. Installa Cloudflare WARP da https://one.one.one.one/
2. Installa SirJoeVPN-Setup.exe (dalle Releases di GitHub)
3. Premi Connetti. La prima volta l'app registra WARP da sola.

Per pubblicare una nuova versione: `git tag v1.0 && git push origin v1.0`
(GitHub compila l'installer e tiene solo le ultime 2 Releases).
